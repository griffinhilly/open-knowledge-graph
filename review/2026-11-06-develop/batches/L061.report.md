## Flags

Factual errors in existing text:
- hessian-matrix-second-derivative-test.md, Core Idea: "local max (det > 0, f_xx > 0), local min (det > 0, f_xx < 0)". This is swapped. f_xx > 0 gives a local min and f_xx < 0 gives a local max. The Explainer and questions in the same file state it correctly.
- hessian-matrix-second-derivative-test.md, Explainer: "like the center of a mountain pass, which is a local maximum along the ridge but a local minimum along the crossing direction". This is reversed. A pass is the lowest point along the ridge and the highest point along the trail that crosses it.
- double-integrals-polar.md, q4 answer: "Without r, you would be treating all polar patches as having the same area... The result would overcount distant regions and undercount regions near the origin". This is backwards. Dropping r undercounts where r > 1 and overcounts where r < 1.
- double-integrals-cartesian-coordinates.md, q0: this question asks which order is "computable in closed form" for sin(y²) over [0,1]². Both orders reduce to ∫₀¹ sin(y²) dy, which has no elementary closed form. The explanation admits this, so the keyed answer and its premise are wrong.
- double-integrals-cartesian-coordinates.md, Explainer: "for continuous f (and more generally for integrable f), the order of integration can be reversed". For Riemann-integrable f, the iterated integrals need not exist. The parenthetical claim is too broad.
- double-integrals-rectangular-regions.md, Explainer last paragraph: lists "accidentally treating an outer variable as a constant inside the inner integral" as an error. Treating the outer variable as a constant in the inner integral is the correct procedure.
- double-integrals-rectangular-regions.md, q3: "regardless of the form of f" is keyed true. The explanation then adds a continuity or integrability condition, so the stem overstates the claim.
- double-integrals.md, q4 answer: "some functions violate Fubini's conditions and the two iterated integrals give different values even though the double integral is well-defined". If the double integral exists (absolutely), Fubini gives equal iterated integrals. The standard counterexamples are functions whose double integral does not exist.
- iterated-integrals-fubini.md, q1 explanation and q3: these say a bounded discontinuous function on a rectangle can have unequal iterated integrals that both exist. This is misleading for Riemann-integrable functions, which give equal iterated integrals whenever they exist. Known bounded counterexamples need non-measurable constructions.
- divergence-theorem.md, q1 explanation and Explainer last paragraph: these say the flux through an open surface is "handled by Stokes' theorem". Stokes' theorem covers the flux of a curl only, not the flux of a general F. The close-the-surface method in the same paragraph is the right tool.
- double-integrals-cartesian.md, Explainer: this calls the region between y = x and y = x² "awkward to describe with horizontal slices". Horizontally it is 0 ≤ y ≤ 1, y ≤ x ≤ √y, which is about as simple.
- double-integrals-polar-coordinates.md, Explainer: this says the Gaussian result is "made accessible only by polar coordinates". Other methods exist, so "only" is too strong.
- flux-integrals.md, q1 explanation: this calls ‖r_u × r_v‖ "the denominator in scalar surface integrals". It is a multiplying factor, not a denominator.
- equations-lines-planes.md, Explainer: "The parameter t plays the role of a signed distance along the line". This holds only when d is a unit vector.
- equations-lines-planes.md, q0 explanation: the arithmetic "5 ≠ 2·(11/2)" is garbled. The conclusion is still right.
- fundamental-theorem-line-integrals.md, q1 explanation: "F = ∇f where f = −GMm/r". With the force pointing toward the mass, the gradient potential is f = +GMm/r, because F = −∇U with U = −GMm/r. Option C's "U(r₂) − U(r₁)" also has the wrong sign for the work done by gravity.
- greens-theorem.md, Explainer: "A field with Q_x − P_y = 0 everywhere has no local rotation; it is called irrotational or conservative". Being conservative also needs a simply connected domain. The (−y, x)/(x² + y²) field is a counterexample. q1 explanation repeats this.
- higher-order-partials.md, q4 explanation: this says continuity of mixed partials "is automatically satisfied by all elementary functions everywhere they are defined". This is false. For example, x^(1/3)-type terms are defined but not smooth at 0.
- level-sets-surfaces.md, Explainer: this lists "saddle surfaces" among surfaces that "cannot be globally written as a graph". The saddle z = x² − y² is a graph.
- limits-continuity-multivariable.md, Explainer: "partial derivatives assume it [continuity]". Partial derivatives can exist at a discontinuity. xy/(x² + y²) with value 0 at the origin is an example.
- limits-continuity-multivariable.md, Explainer: "if the expression in polar form tends to L independently of θ, the limit is established". The convergence has to be uniform in θ. x²y/(x⁴ + y²) tends to 0 for each fixed θ but has no limit.
- distance-and-distance-formula-3d.md, Explainer: this lists three metric axioms, "d(A, A) = 0, symmetry, triangle inequality". It omits d(A, B) > 0 for A ≠ B, so the list is incomplete.

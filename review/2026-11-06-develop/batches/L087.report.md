## Flags

- matrix-exponential.md, Core Idea: "eᴬ = PeᴰPP⁻¹" has a stray P. It should read eᴬ = PeᴰP⁻¹.
- matrix-exponential.md, Explainer: "resonance in coupled oscillators, where the response grows without bound even at bounded input". For the homogeneous system x' = Ax, terms like te^{λt} still decay when Re(λ) < 0. Unbounded growth from a Jordan block needs Re(λ) ≥ 0, and "bounded input" refers to a forced system the page does not set up.
- matrix-norms-conditioning.md, Core Idea: "max norm ||A||_∞". ||A||_∞ usually means the induced infinity norm (max absolute row sum). "Max norm" usually means max |a_ij|. The label mixes the two.
- null-space.md, Q4 short-answer answer: "a 4-dimensional flat (hyperplane through the origin)". A 4-dimensional subspace is a hyperplane only in ℝ⁵. The question does not give the ambient dimension.
- orthogonal-projections.md, Q3 explanation: "the basis vectors are not independent in the inner-product sense" and "requires the Gram matrix (AᵀA)⁻¹Aᵀ". The Gram matrix is AᵀA, and the wording about independence is muddled.
- positive-definite-matrices.md, Q3 (true-false, answer false): "AᵀA ... with more rows than columns is typically positive definite". A generic tall matrix has full column rank, so AᵀA is typically positive definite. The intended false statement needs "always".
- row-echelon-form.md, Q4 (true-false, answer false): "more unknowns than equations usually has infinitely many solutions". Generic such systems are consistent, so "usually" makes this arguably true. The explanation argues against "always".
- row-echelon-form.md, Explainer: "A system with free variables has infinitely many solutions". This holds only if the system is consistent.
- reduced-row-echelon-form.md, Q3 explanation and Explainer: "two matrices have the same RREF if and only if they represent equivalent linear systems with the same solution set". Same RREF means row equivalent. Two inconsistent augmented systems share the empty solution set but can have different RREFs.
- scalar-multiplication.md, Q3 (true-false, answer true): "For any nonzero vector v and any scalar c, cv is always parallel or antiparallel to v". When c = 0, cv is the zero vector, which has no direction.
- span-and-basis.md, Explainer: "The span of two vectors that point in different directions is all of R²". Opposite (antiparallel) vectors point in different directions but span only a line. It should say "non-parallel".
- rank-nullity-theorem.md, Explainer and Q5 answer: they describe the kernel and image as two subspaces that "account for all of V together". The image lives in W, not V. The theorem matches dimensions only.
- vector-spaces.md, Explainer: "The next four govern scalar multiplication" but only three properties follow. Associativity of scalar multiplication and 1·v = v are missing. The Core Idea's "eight axioms" list also counts closure while merging the two distributive laws, which is a nonstandard count.
- systems-of-linear-equations.md, Core Idea: "The solution set forms an affine subspace". This holds only when the system is consistent.
- Prerequisites: none.

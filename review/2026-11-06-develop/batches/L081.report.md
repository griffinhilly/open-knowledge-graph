- fourier-series-lp-theory.md Q3: "converge to f(x) for nearly every x ... answer: false". Carleson's theorem says Fourier series of L² functions converge a.e., so with "nearly every" the statement is true. Probably garbled from "every x".
- fourier-series-lp-theory.md Explainer: "it holds for 1 < p < ∞ (by the Riesz-Fischer theorem and M. Riesz interpolation)". Lᵖ norm convergence comes from M. Riesz's theorem on the conjugate function (boundedness of the Hilbert transform), not Riesz–Fischer plus interpolation.
- bessel-inequality-parseval-identity.md Explainer: "with the trigonometric basis {1/√(2π), cos(nx)/√π, sin(nx)/√π}, ... the sum of the squares of all its Fourier coefficients equals (1/2π)∫|f|²". With that normalized basis the sum equals ∫|f|², with no 1/2π factor.
- banach-spaces.md Q5 and Explainer, and lp-completeness.md Explainer: they say the Hahn–Banach theorem needs Banach spaces or completeness. Hahn–Banach holds in every normed space.
- bounded-linear-operators.md Core Idea: "‖T(x)‖_X ≤ C‖x‖_X". The left side should be ‖T(x)‖_Y.
- bounded-linear-operators.md Q1 explanation: "Option C is true for metric spaces generally". This is false: f(x) = 1/x on (0,1) is continuous but does not preserve Cauchy sequences.
- closed-graph-theorem.md Q5 explanation and Explainer: they say differential operators and "unbounded operators" are "most naturally verified continuous" by the closed graph theorem. Unbounded operators are not continuous. Differential operators are typically closed but unbounded, because their domains are not complete in the relevant norm.
- compact-operators.md Explainer: "the image of a bounded set under a matrix is always bounded and closed — hence compact". The image need not be closed; it is relatively compact. Also, Q1 and Q5 attribute ‖eₙ − eₘ‖ = √2 to Bessel's inequality; it follows from Pythagoras/orthonormality.
- fredholm-alternative.md Q3 explanation: the identity is a poor counterexample. With T = I, I − T = 0 has a nontrivial kernel, so the dichotomy holds. A real failure: I − T = S (the shift), which is injective but not onto.
- fredholm-alternative.md Explainer: "The proof uses the Baire category theorem". The standard Riesz–Schauder proof uses the Riesz lemma, not Baire.
- fatou-lemma.md Q1: "the pointwise lim inf of fₙ is 0 everywhere" for fₙ = n·1_{[0,1/n]}. At x = 0, fₙ(0) = n → ∞, so the liminf is 0 only almost everywhere. The explanation also calls this concentration "mass escaped to infinity". Also, the Explainer's "smallest accumulation point — the eventual floor below which the sequence stays infinitely often" is garbled, and "DOM theorem" is a typo.
- fatou-lemma-measure-theory.md Explainer: it defines liminf as "the largest function that is ≤ fₙ for all sufficiently large n". This is imprecise, since there is no single N in general.
- fubini-theorem.md Explainer: it omits the σ-finiteness hypothesis for Tonelli and Fubini. "The product measure distributes mass uniformly across the product" is not meaningful.
- hahn-banach-theorem.md Explainer: "a subspace can be dense in the whole space, and extensions must be compatible with limits in a topologically subtle way". Extension from a dense subspace is the trivial, unique case. The geometric form also needs hypotheses (closed or open convex set) that the text omits.
- hilbert-spaces.md Explainer: "infinite superpositions always converge". Only square-summable coefficient sequences converge.
- holders-inequality.md Q1 and Q3: on finite measure spaces, non-conjugate exponents do give Hölder-type bounds with a measure factor. "g ∈ L² but not L^(3/2)" is impossible on a finite measure space. Q3's blanket "cannot be extended to non-conjugate pairs" overstates. The Explainer also has the typo "bq/q" for b^q/q.
- lebesgue-integral-non-negative.md Explainer: "A function like 1/√x near 0 may have infinite integral". ∫₀¹ x^(−1/2) = 2, which contradicts the file's own Q2.
- lebesgue-integral.md Q1, Q5 and Explainer: they say Lebesgue integration works because "the measure of the set of discontinuities matters". That is the Riemann integrability criterion. The Dirichlet function is discontinuous everywhere. The Explainer also says f⁺ and f⁻ "are already integrable" when it means their integrals are defined.
- lebesgue-integral-simple-functions.md Core Idea: "𝟙ₐᵢ" should be 𝟙_{Aᵢ}. The Explainer allows real coefficients without restricting to finite-measure sets (∞ − ∞ risk).
- lebesgue-measure-euclidean-space.md Q1 explanation: "cannot be approximated by any finite or even σ-finite collection of 3D boxes with positive total volume" is garbled. Q5: "boxes of height ε centered on the plane" means a single infinite slab, which has infinite volume. The Explainer's "any k-dimensional set (k < n) ... has λₙ-measure zero" needs smoothness or Lipschitz; some topologically 1-dimensional curves have positive area.
- lebesgue-outer-measure.md Q5 explanation and Explainer: they call outer measure a "pre-measure". A pre-measure is a countably additive set function on an algebra.
- linear-functionals-dual-spaces.md Core Idea: it defines "linear functional" as bounded. The Explainer states (ℓᵖ)* = ℓ^q and (Lᵖ)* = L^q without the range 1 ≤ p < ∞ (p = 1 needs σ-finiteness for Lᵖ). Q1 calls the Riesz map an isomorphism; over ℂ it is conjugate-linear.
- lp-completeness.md Q4 explanation: "Norm convergence is strictly weaker [than pointwise]". Neither mode implies the other. The Explainer credits Hölder; the Riesz–Fischer proof uses Minkowski.
- lp-norm-metric.md Q5 explanation: "Every downstream result ... from Hölder's inequality ... rests on [Minkowski]". This is circular, since Hölder is used to prove Minkowski.
- lp-space-completeness-riesz-fischer.md Explainer: "a constant sequence fₙ = 1_ℚ would converge to something outside the space". A constant sequence converges to itself. "Absolutely convergent series in Lᵖ are convergent — a direct consequence of the norm structure plus Minkowski" is also wrong: this property is equivalent to completeness, not a consequence of having a norm.
- measurable-functions.md Core Idea: "natural notion of 'integrable function'". Measurable is not the same as integrable.
- measurable-sets-properties.md Explainer: "Vitali sets ... are explicitly excluded from any σ-algebra by their construction". The power set is a σ-algebra that contains them; they are excluded from the Lebesgue σ-algebra. Q2's options C and D rely on the same idea.
- bessel-parseval.md Explainer: "a Hilbert space — an infinite-dimensional inner product space" (Hilbert spaces can be finite-dimensional). It also says the Riesz representation theorem is "the machinery that makes this convergence rigorous"; the convergence comes from completeness, not Riesz representation.

### Suspected wrong or missing prerequisites

- `spectral-theorem-compact-self-adjoint -> fredholm-alternative` (hard): this is not needed, because the alternative holds for general compact operators on Banach spaces. `compact-operators` (currently soft) should be the hard prerequisite.
- `riesz-representation-theorem-hilbert -> bessel-parseval` (hard): this is not needed for Bessel/Parseval.
- `lp-completeness -> banach-spaces` and `lp-space-completeness-riesz-fischer -> banach-spaces` (builds-toward): these are backwards. Banach spaces is the general concept that these topics instantiate. banach-spaces also cites Riesz–Fischer.

- `linear-functionals-dual-spaces -> hilbert-spaces` (builds-toward): the topic uses the Riesz representation theorem for Hilbert spaces, so hilbert-spaces should be a prerequisite.

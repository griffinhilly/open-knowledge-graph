## Flags

### Suspected factual errors in existing text

- ruler-compass-constructions-algebraic.md, Core Idea: "A complex number is constructible ... if and only if its minimal polynomial over Q has degree a power of 2." Wrong. The degree condition is necessary but not sufficient. The correct criterion: the splitting field of the minimal polynomial has degree a power of 2 (its Galois group is a 2-group). The same Core Idea says "Consequently ... π is transcendental." Transcendence of π is a separate theorem and does not follow from constructibility.
- ruler-compass-constructions-algebraic.md, Questions item 2 (true-false, answer true): it states the same false "iff degree is a power of 2" claim. The explanation adds "The converse also holds". This contradicts ruler-and-compass-constructions.md item 3, which correctly says degree 4 does not imply constructible.
- ruler-compass-constructions-algebraic.md, Explainer para 4: "constructible if and only if [Q(α) : Q] is a power of 2, which happens if and only if the Galois group ... is a 2-group." The first "iff" is false. The two conditions are not equivalent.
- principal-ideal-domains.md, Explainer: "gcd(6, 10) = 2, and indeed 2 = 6(-1) + 10(1)." The arithmetic is wrong: 6(−1) + 10(1) = 4. A correct form is 2 = 6(2) + 10(−1).
- insolvability-quintic.md, Questions item 0 explanation: "[x⁵ − 1] its Galois group is Z₅". Over ℚ the splitting field is ℚ(ζ₅), whose Galois group is (ℤ/5ℤ)^× ≅ ℤ₄, not ℤ₅.
- insolvability-of-the-quintic.md, Explainer: "For thousands of years, mathematicians searched for a formula that would solve fifth-degree (quintic) equations." Cubic and quartic formulas date from the 16th century. The search for a quintic formula lasted about three centuries, not thousands of years.
- ruler-and-compass-constructions.md, Explainer: "Gauss proved this at age 19 by showing constructibility of a regular n-gon is equivalent to the Galois group ... being a 2-group." Gauss proved sufficiency, and he did not use Galois groups. Necessity is usually credited to Wantzel. The 17-gon at 19 is right. The "iff proved by Gauss" framing is not.
- ring-homomorphisms.md, Questions item 3 explanation: two attempted counterexamples are tested and found to work ("... actually this one works", "actually also fine"). The explanation never gives a valid counterexample. A valid one: n ↦ 2n on ℤ preserves addition, but φ(1·1) = 2 ≠ 4 = φ(1)φ(1).
- group-definition-examples.md, Questions item 0 explanation: contains "−3 is odd so inverses exist... wait, −3 is odd". It also says option D ("the additive inverse of an odd integer is not odd") is "technically true", which is false.
- group-definition-examples.md, Explainer: "The six rotations of an equilateral triangle form a group." An equilateral triangle has 3 rotations. Its 6 symmetries include 3 reflections.
- second-isomorphism-theorem-groups.md, Explainer para 3: "(4 elements on the left, 3 elements on the right... wait, Z₁₂/N has 3 cosets)". Draft text left in place.
- irreducibility-criteria.md, Core Idea: "Eisenstein's criterion provides a sufficient condition for irreducibility over fields and principal ideal domains." Eisenstein applies to polynomials over an integral domain (for example a UFD) with a prime element, and it gives irreducibility over the fraction field. It does not apply "over fields": a field has no prime elements.
- irreducibility-criteria.md, Questions item 4 answer: "rational roots only helps for cubics and quartics directly". For quartics, having no rational root does not prove irreducibility. Example: x⁴ + 4 = (x² + 2x + 2)(x² − 2x + 2).
- irreducibility-criteria.md, Explainer para 2: the Eisenstein statement leaves out the condition that p does not divide the leading coefficient.
- polynomial-rings.md, Questions item 4 answer: "Over infinite rings or fields, the two notions coincide". This holds for infinite integral domains, not all infinite rings. For example, x² − x vanishes on every element of an infinite Boolean ring.
- polynomial-rings.md, Questions item 1 explanation: it calls option D "more commonly the statement of Gauss's lemma", yet the key is option A. This muddles the item.
- maximal-and-prime-ideals.md, Explainer para 2: "which forces a unit multiple of a to land in M, producing the inverse". The reasoning is garbled. Correct reasoning: M + (a) = R, so 1 = m + ra, so [r][a] = 1.
- maximal-and-prime-ideals.md, Questions item 3 explanation: "in principal ideal domains that are also fields" is confused. The standard fact is that in a PID every nonzero prime ideal is maximal.
- maximal-and-prime-ideals.md, Core Idea: maximal ideals exist in any commutative ring with unity. This needs the ring to be nonzero.
- maximal-prime-ideals.md, Core Idea: "no ideal properly contains M". It should say no proper ideal properly contains M, since R itself contains M.
- maximal-prime-ideals.md, Questions item 0 explanation: "In ℤ, an ideal (n) is prime iff n is prime." This leaves out (0), which is prime.
- ring-definition-examples.md, Explainer para 4: "(a + b)² = a² + 2ab + b² hold" in a ring. That holds only when ab = ba. In general (a + b)² = a² + ab + ba + b².
- ring-definition-examples.md, Questions item 4 answer: "Without it, you would simply have two unrelated abelian groups". Multiplication in a ring is not a group operation.
- splitting-fields.md, Questions item 4 answer: "it is contained in every other field extension of F in which f splits completely". Wrong. Minimality means the field is generated over F by the roots. Another splitting extension contains an isomorphic copy, not the field itself.
- subrings-ideals.md, Explainer para 2: subrings are defined to contain 1, and then "An ideal I ⊆ R strengthens the subring condition". Under that convention a proper ideal is not a subring.
- subgroups-subgroup-test.md: the Core Idea calls "nonempty, closed under operation and inverses" the one-step test. The Explainer calls ab⁻¹ ∈ H the one-line version and the other the two-step test. The naming is inconsistent. The Explainer also says "three of those are essentially free". Only two (associativity and identity) are.
- group-basic-properties.md, Explainer para 2: uniqueness of the identity is "proved by contradiction". It is a direct proof. The inverse-uniqueness sentence also uses ac = e without stating it.
- orbit-stabilizer-theorem.md, Questions item 3 explanation: the ℤ₂ example ("r fixes both a and b but swaps nothing") is muddled. The conclusion is right, but the example should be stated as the trivial action.
- permutation-groups.md, Explainer: "A₅ is simple (has no normal subgroups)". It should say no nontrivial proper normal subgroups. sign-of-a-permutation.md, Explainer, has the same slip ("no proper normal subgroups").
- sign-of-a-permutation.md ("(123) = (12)(13)") and sign-permutation.md ("(a₁ ... aₖ) = (a₁ a₂)(a₁ a₃)···(a₁ aₖ)"): these hold only when the left factor is applied first. permutation-groups.md uses the opposite convention, in which the right factor acts first.
- quotient-rings.md, Core Idea: "addition and multiplication defined component-wise". The operations are defined on representatives, not component-wise.
- subrings-and-ideals.md, Core Idea: "making it a kernels of homomorphisms" is a grammar slip.
- Several true-false items have garbled stems ("Most integral domain is a field", "most prime ideal is maximal", "Most ring is expected to have", "they is expected to lie", "verify most four group axioms"). They appear in integral-domains, maximal-and-prime-ideals, ring-definition-examples, ring-definition-and-examples, orbit-stabilizer-theorem, subgroups-subgroup-test, subrings-ideals and polynomial-rings.

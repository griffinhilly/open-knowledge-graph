## Flags

### Suspected factual errors in existing text
- cycle-notation-decomposition.md, Q0: "Student B writes (1 4)(2 4)(3 4)(1 4)(2 4)". That product is not (1 2 3 4) under either composition convention. Applying the right factor first gives (1 3 2 4). The answer "both are correct" is therefore wrong as written. Also, Student A's (1 2)(1 3)(1 4) and the Explainer's formula (a₁ a₂)(a₁ a₃)···(a₁ aₖ) hold only if the left factor is applied first. That convention is never stated.
- cycle-notation-decomposition.md, Q4 answer: "Each transposition flips exactly one pair (xᵢ − xⱼ)". This is false. A transposition (i j) reverses 2(j − i) − 1 factors, which is an odd number. That number is 1 only for adjacent indices.
- dihedral-groups.md, Explainer: "the n rotations are all even permutations, while the n reflections are all odd". This is false for even n. In D₄, r = (1 2 3 4) is odd, and the edge reflection (1 2)(3 4) is even.
- first-isomorphism-theorem-for-rings.md, Explainer: "φ: ℝ[x] → ℝ defined by φ(f) = f(√2). The kernel ... is the ideal (x² - 2)". This is wrong. Over ℝ the kernel is (x − √2), and ℝ[x]/(x² − 2) ≅ ℝ × ℝ, not ℝ. The example works over ℚ[x] with image ℚ(√2).
- first-isomorphism-theorem-rings.md, Q3 explanation: "If φ: Z → Z is multiplication by 2". That map is not a ring homomorphism, since 2(ab) ≠ (2a)(2b).
- first-isomorphism-theorem-groups.md, Q0 explanation: "The kernel captures which elements are in the same coset (have the same image), not which elements map to the identity specifically". This is wrong. The kernel is exactly the set of elements that map to the identity.
- first-isomorphism-theorem-groups.md, Q4 answer: "a coset has infinitely many representatives" is false for finite groups. The answer also says well-definedness is "exactly" the criterion for being in the same coset, but well-definedness gives only one direction. The converse is injectivity.
- first-isomorphism-theorem-for-groups.md, Explainer: "the map ℝ → ℝ/ℤ (real numbers mod 1) shows ℝ/ℤ is isomorphic to the circle group". The map that shows this is ℝ → circle, t ↦ e^{2πit}, with kernel ℤ.
- galois-groups.md, Core Idea: "For separable extensions, the order of the Galois group equals the degree of the extension". This needs Galois (normal and separable). ℚ(∛2)/ℚ is separable of degree 3 with trivial automorphism group, which is the file's own Q0. Q3's explanation repeats the error: "for separable (and hence Galois) extensions".
- basic-group-properties.md, Explainer: "The associativity axiom is the key engine driving both proofs". The proof that the identity is unique (e = e·e' = e') uses no associativity. The Q4 answer says the same thing ("using only associativity and the identity property").
- cayley-theorem.md, Explainer and Q2: they suggest ℤ₃ "could in principle be represented more compactly" than inside S₃. But S₃ is the smallest symmetric group that contains ℤ₃. A better example would be S₃ landing in S₆. Q0 also calls option A false, but on a finite set an injective map from G to G is bijective. Core Idea says "some symmetric group Sₙ", which fails for infinite G, where the target is Sym(G).
- cosets-lagrange-theorem.md, Q4 explanation: "right-multiplying H by a fixed element a is a bijection H → aH". It should say left-multiplying.
- cyclic-groups.md, Q2 explanation: "exactly one subgroup of order d, namely ⟨d⟩". In ℤ/nℤ, ⟨d⟩ has order n/d, not d.
- classification-finite-abelian-groups.md, Q1 option D: "isomorphic if and only if they have the same number of elements of each order". For finite abelian groups this statement is true, so the item is ambiguous.
- applications-sylow-theorems.md, Q4 answer: it says element counting shows that if every prime had several Sylow subgroups, their elements "would collectively exceed |G|". This overgeneralizes. It works only when the subgroups meet trivially, and it fails for simple groups such as A₅.
- applications-of-sylow-theorems.md, Explainer: "both Sylow p-subgroups must account for the entire group" for order p². The phrasing is muddled, since the Sylow p-subgroup is G itself.
- fundamental-theorem-galois-theory.md, Q0: options A and C both give the value 2, so a learner who picks A has the right number but is marked wrong.
- finite-fields.md, Explainer: "After n applications, φⁿ ... is the identity ... So φ has order exactly n". The text shows φⁿ = id but never shows that no smaller power is the identity. The derivation of |𝔽| = pⁿ from "the additive group has characteristic p" is also loose.

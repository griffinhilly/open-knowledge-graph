- domains/mathematics/measure-theory-and-functional-analysis/monotone-convergence-theorem-analysis.md, question 0 explanation: "f₄(1/4)=4, f₅(1/4)=0". With fₙ = n·χ_(0,1/n) (open interval), 1/4 ∉ (0, 1/4), so f₄(1/4) = 0. The sequence at 1/4 is 1, 2, 3, 0, 0, ... The point about non-monotonicity still stands.
- domains/mathematics/measure-theory-and-functional-analysis/monotone-convergence-theorem-analysis.md, Explainer: "For Riemann integrals, the swap requires uniform convergence". Uniform convergence is sufficient, not necessary (for example, the Arzelà bounded convergence theorem allows the swap under uniform boundedness when the limit is Riemann integrable).
- fatou-lemma-measure-theory -> monotone-convergence-theorem-analysis: listed as a soft prerequisite, but the same file lists fatou-lemma-measure-theory in builds-toward. Fatou's lemma is usually proved from MCT, so the prerequisite edge looks reversed (same likely applies to fatou-lemma -> monotone-convergence-theorem-analysis).
- closed-graph-theorem -> open-mapping-theorem: listed as a soft prerequisite, while the same file lists closed-graph-theorem in builds-toward. The closed graph theorem is usually derived from the open mapping theorem, so the edge looks circular.
- domains/mathematics/measure-theory-and-functional-analysis/open-mapping-theorem.md, Explainer: "conclude that two natural norms on the same space are equivalent whenever they define complete spaces". The bounded inverse theorem gives equivalence of two complete norms only when one is dominated by the other (‖x‖₁ ≤ C‖x‖₂). Two complete norms need not be equivalent in general.
- domains/mathematics/measure-theory-and-functional-analysis/operator-norm.md, Explainer: "Submultiplicativity is what makes the operator norm a Banach algebra norm on ℒ(X, X)" (and question 1 explanation). ℒ(X, X) is a Banach algebra only when X is complete; otherwise it is a normed algebra.
- domains/mathematics/measure-theory-and-functional-analysis/orthogonality-and-projections.md, question 4 explanation: "the distance is a strictly convex function". The norm itself is not strictly convex along lines through x; the squared distance is. The uniqueness argument via the parallelogram law is correct.
- domains/mathematics/measure-theory-and-functional-analysis/orthogonality-hilbert-spaces.md, Explainer and question 4 answer: "{1, cos(x), sin(x), cos(2x), sin(2x), ...} form an orthonormal basis ... each with unit norm". In L²[−π,π] these have norms √(2π) and √π; they are orthogonal but must be normalized (1/√(2π), cos(nx)/√π, sin(nx)/√π) to be orthonormal. The question 4 explanation's (1/π) factor already assumes the unnormalized system, which contradicts "unit norm".
- domains/mathematics/measure-theory-and-functional-analysis/orthonormal-bases-in-hilbert.md, Explainer, question 1 and question 4: "{1, cos(2πnx), sin(2πnx)} form an orthonormal basis for L²([0,1])". On [0,1], ∫cos²(2πnx) dx = 1/2, so the orthonormal basis is {1, √2 cos(2πnx), √2 sin(2πnx)}.

## Flags

### Suspected factual errors in existing text
- archimedean-property.md, Explainer: "The rational numbers ℝ and ℚ do not contain such elements" — ℝ is not the rationals; likely meant "The real numbers ℝ and the rationals ℚ".
- bolzano-weierstrass-theorem.md, Questions 2 and 3: "most bounded sequence of rationals has..." and "Bolzano-Weierstrass implies that most bounded sequence in ℝ converges" — "most" looks like a bad substitution for "every"; the statements are ungrammatical and the intended claim is about "every".
- compact-sets-heine-borel.md, Question 0 explanation: the cover {[0, 1 − 1/n)} is not a cover by open subsets of ℝ (and n = 1 gives the empty set). Open sets such as (−1, 1 − 1/n) would make the example correct.
- compact-sets.md, Question 2: "Nearly every closed subset of ℝ is compact" — garbled "Every"; its explanation also uses the cover {[0, n)}, whose sets are not open in ℝ.
- compact-sets.md, short-answer answer: calls (0, 1] a "bounded but open set"; (0, 1] is not open. It is bounded but not closed.
- connected-sets.md, Question 3: "disconnected mainly if it can be written as a union of two disjoint non-empty closed sets (in the subspace topology)" — "mainly" garbles the statement, and the explanation itself says the closed-set formulation is equivalent, which contradicts answer false.
- epsilon-delta-continuity.md, Explainer paragraph 3: "What is not required is a single δ that works for all ε at once; that stronger condition defines something else (uniform continuity...)". Uniform continuity asks for one δ (per ε) that works at all points c, not one δ for all ε.
- cauchy-sequences-completeness.md, Explainer: says Cauchy completeness "is not a theorem you prove from more basic facts about ℝ" while the paragraph before says the hard direction is proved from completeness via Bolzano-Weierstrass. With the least-upper-bound axiom as the base, Cauchy completeness is a theorem. Mild internal tension.
- fundamental-theorem-calculus-rigorous.md, Explainer paragraph 3: proves Part 2 by applying Part 1 to G(x) = ∫ₐˣ f, which needs f continuous; paragraph 4 then says Part 2 needs only integrability. The general proof uses the Mean Value Theorem on each partition subinterval.
- heine-borel-theorem.md, Explainer paragraph 2: "Take the cover of singletons {n−1, n+1} for each n ∈ ℤ" — these are not singletons and not open; the cover described does not work as stated. Intervals (n − 1/2, n + 1/2) would.
- heine-borel-theorem.md, Question 0 explanation: "ℝ is neither bounded" (garbled). Question 2: "A closed subset of ℝ is typically compact" (garbled "Every").
- interchange-limit-derivative.md, Core Idea and Question 2: the theorem's conclusion that fₙ converges uniformly needs a bounded interval. On ℝ, fₙ(x) = x/n has fₙ′ → 0 uniformly and fₙ(0) → 0, but fₙ does not converge uniformly; "on the entire domain" (answer true) is false for unbounded domains.
- interchange-limit-integral.md, Question 1 explanation: says a uniform bound plus pointwise convergence is only the Lebesgue Dominated Convergence setting. For Riemann integrals, Arzelà's bounded convergence theorem gives the interchange under a uniform bound when the limit is Riemann integrable, so the dismissal is overstated. Explainer paragraph 1: spikes "remaining bounded pointwise" is misleading, since their sup grows like n.
- introduction-lebesgue-integral.md, Explainer paragraph 2: "the supremum over all simple functions bounded below by f" should be simple functions bounded above by f (0 ≤ φ ≤ f).
- introduction-lebesgue-measure.md, Question 3: "differ primarily on the set of rational numbers" — garbled "only"; with "primarily" the statement is not well defined. Explainer: "nowhere Riemann integrable" is loose (integrability is not a pointwise property).
- intermediate-value-theorem-rigorous.md, Question 3: "Nearly every function ... should have a zero" (garbled "Every").
- limit-superior-and-inferior.md, Question 3: "the supremum of most values" (garbled "all"). Explainer: "lim inf aₙ = lim_{n→∞} inf_{k≥n} aₙ" should be aₖ. Explainer paragraph 4: "use lim sup across a domain to define the sup-norm" is wrong; the sup-norm is a supremum, not a lim sup.
- limit-superior-inferior.md, Question 0 explanation contains a drafting artifact ("(odd terms: −1 + 1/n → −1) wait — even terms give...") and garbles which terms go where. Explainer paragraph 2: lim sup is "the largest value the sequence reaches infinitely often"; it is the largest value approached (subsequential limit), which need not be reached.
- monotone-convergence-theorem.md, Question 3 explanation: the sketch of MCT ⇒ LUB ("pick an increasing sequence of elements approaching sup S") assumes sup S exists, which is circular. A standard route uses bisection plus MCT.
- mean-value-theorem-rigorous.md, Explainer paragraph 2: the interior-extremum fact is Fermat's theorem, not "the first-derivative test". Paragraph 3: "proving continuity from differentiability" does not use the MVT.
- open-closed-sets-real-line.md, Question 3: "Nearly every subset of ℝ is expected to be either open or closed" (garbled). Explainer: says ℝ satisfies both definitions "vacuously"; that applies to ∅, not ℝ.
- ordered-field-axioms.md, Question 3: "nearly every bounded monotone sequence" (garbled "every").
- pointwise-convergence-function-sequences.md: has two `## Questions` blocks with near-duplicate items. Last explanation: "uniform convergence is exactly strong enough" for differentiability is false (uniform convergence of fₙ does not preserve differentiability).
- pointwise-convergence-functions.md, Question 3: "f is expected to also be continuous" (garbled "must").
- properties-riemann-integral.md, Explainer paragraph 4: "∫[a,b] f = ∫[a,c] f + ∫[b,c] f" should end ∫[c,b] f.
- riemann-integral-properties.md, Explainer paragraph 2: "Darboux sums are already linear in the function" is false; U(f + g, P) ≤ U(f, P) + U(g, P) can be strict (f = x, g = −x on [0, 1] with P = {0, 1}). Question 2: "f(x) ≤ g(x) for most x" (garbled "all"). Paragraph 4 uses "ᵦ" (beta) for the subscript b.

It also says "Functions discontinuous on a dense set (like Dirichlet's function) are not Riemann integrable", which is false as a general claim and contradicts Question 0 (discontinuous exactly at the rationals, still integrable). The Dirichlet function fails because its discontinuity set is all of [0, 1]. Question 0 also omits boundedness from its stem.

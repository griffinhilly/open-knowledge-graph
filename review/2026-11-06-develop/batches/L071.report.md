## Flags

Suspected factual errors in existing text:
- fundamental-group-definition.md (Explainer para 4 and true-false Q4): "a solid torus and S¹ × D² both have fundamental group ℤ" is given as an example of non-homeomorphic spaces with isomorphic π₁. The solid torus is S¹ × D², so they are homeomorphic. A valid example: S¹ and the solid torus, or S¹ and ℝ² ∖ {0}.
- heine-borel-compact-sets.md (Core Idea): "does not generalize to all metric spaces (e.g., [0,∞) is closed but not compact)". [0,∞) is unbounded, so it does not illustrate failure of the theorem. A valid example: a closed ball in an infinite-dimensional normed space, or ℕ with the discrete metric. Also, Explainer last para says "In higher-dimensional and infinite-dimensional settings": Heine-Borel holds in every ℝⁿ, so "higher-dimensional" is wrong.
- homeomorphisms-definition-properties.md (MC Q1 option C and explanation; Explainer para 2) and homeomorphisms-topological-equivalence.md (MC Q1 option B and explanation; Explainer para 1): both say f⁻¹ fails to be continuous because a small open arc around (1, 0) pulls back to a set near 0 and near 1 that is "not open in [0, 1)". That set, [0, ε) ∪ (1 − ε, 1), is open in [0, 1). The real failure: [0, ε) is open in [0, 1), but its image under f is a half-open arc, which is not open in S¹.
- homeomorphisms-topological-equivalence.md (Core Idea): "same shape if one can be continuously deformed into the other without tearing or gluing". This describes isotopy, not homeomorphism (a knotted circle is homeomorphic to a round one). Loose, but it misleads.
- hausdorff-spaces.md (Explainer para 3): "From this it follows that singletons {x} are closed in any T₁ space". Closed singletons are the definition of T₁. They do not follow from uniqueness of limits.
- limit-points-topology-definition.md (short-answer Q5 answer): without the "different from x" clause, "every set would contain all its 'limit points,' all sets would be closed". This is false. Dropping the clause gives adherent points, which form the closure. So (0, 1) would still be missing the adherent points 0 and 1, and would still not be closed.
- interior-closure-operators.md (Core Idea): "preserve unions (or intersections)". Closure preserves finite unions only, and interior preserves finite intersections only.
- local-compactness.md (Explainer para 4): "For topological manifolds, local compactness is part of the definition: it ensures every point has a neighborhood homeomorphic to an open ball". This is backwards. Manifolds are locally Euclidean by definition, and local compactness follows from that. Also para 3: "every open cover of X* either omits ∞ (covered by X's topology)". Every open cover of X* must contain a set containing ∞.
- locally-connected-spaces.md (Core Idea): "Connected + locally connected implies path-connected". This is false. The correct hypothesis is locally path-connected. The lexicographically ordered square is connected and locally connected but not path-connected. Also "universal covers exist": that needs path-connected, locally path-connected and semilocally simply connected.
- metric-topology-from-metric.md (true-false Q3 explanation; Explainer last para): says second-countability and regularity are "required" for metrizability and that they "characterize" metrizable spaces. Urysohn's conditions are sufficient, not necessary: an uncountable discrete space is metrizable but not second-countable.
- metrization-theorems.md (MC Q1 and Explainer last para): says that to use completeness or Cauchy sequences, you check a metrization theorem first. Completeness is not a topological property, and it depends on the chosen metric (ℝ with |arctan x − arctan y| is not complete). Metrizability alone does not make "completeness" well defined. Q1 also implies that second-countability must be checked, which is not necessary.
- neighborhood-basis-topology.md (Explainer para 3): "Consider the long line or ordinal spaces: at certain points, every neighborhood basis must be uncountable". The long line is first-countable (locally homeomorphic to ℝ). Only the ordinal example (ω₁ in [0, ω₁]) is correct.
- neighborhoods-topology-definition.md (Explainer para 3): "first-countability is exactly what allows sequences to detect topological structure". First-countability is sufficient, not necessary (Fréchet–Urysohn spaces). Also para 4: "ε defines a neighborhood (x − ε, x + ε) of the output" should be centered at f(x).
- normal-spaces.md (Explainer para 2): lists "the long line" as a space where disjoint closed sets cannot be separated. The long line is normal, because every linearly ordered space is normal. Also true-false Q3 and MC Q2: the notation "T₁ ⊂ T₂ ⊂ T₃ ⊂ T₄ containments do NOT hold" is confused. As classes of spaces (with T₁ included in T₃ and T₄), T₄ ⊂ T₃ ⊂ T₂ ⊂ T₁ does hold. The point being made is that the reverse implications fail.
- normality-t4-axiom.md (Core Idea): "any continuous function on a closed set extends to the whole space (Tietze extension)". Tietze covers real-valued (or interval-valued) functions only. For example, the identity on ∂D² = S¹ does not extend to a map D² → S¹.
- open-covers-finite-subcovers.md (Explainer para 2): "Cover [0, 1] by the same collection and add (−0.1, 0.1): now the point 0 is covered, and 1 is always covered". The point 1 is in no set (1/n, 1), so that collection does not cover [0, 1].
- open-sets-in-topological-spaces.md (Explainer para 2; short-answer Q5): says that requiring arbitrary intersections to be open would collapse "the topology to the discrete one" and make "every set" open. That is true for ℝ (or any T₁ space), but stated generally it is false: the indiscrete topology and all finite topologies are closed under arbitrary intersections.

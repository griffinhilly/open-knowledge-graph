## Flags

### Suspected factual errors in existing text
- cost-minimization-and-factor-demand.md, Q0 (MRTS = 3, w1/w2 = 2): answer key is 2 ("Use more of input 2 and less of input 1"). This is backwards. MRTS = MP1/MP2 = 3 > w1/w2 means input 1 gives more output per dollar, so the firm should use more input 1 and less input 2 (option index 1). The explanation's own arithmetic (give up 3 units of input 2, buy 1 unit of input 1, net saving w2) describes substituting toward input 1 but then concludes "toward input 2". The Explainer correctly says the firm "is using too much of input 2". My misconception bullet states the correct direction.
- adverse-selection-screening.md, Explainer and Q3/Q4: "information rent" is used for the efficiency loss ("The gap between the first-best ... and second-best ... represents the information rent"). Information rent is the surplus the informed type keeps above its reservation utility. The distortion is a separate efficiency cost. Also "The high type gets an efficient contract but pays a premium that extracts their information rent" is confused.
- adverse-selection.md, Explainer: signaling is "a costly action that only high types can afford". Low types can afford it; they choose not to because it is not profitable.
- arrow-impossibility-theorem.md, Core Idea omits the "three or more alternatives" condition and that the theorem concerns rules producing a complete transitive social ranking. Explainer lists approval voting among systems that violate Arrow's conditions; approval voting does not take rankings as input, so Arrow's framework does not apply directly.
- auction-formats-and-equivalence.md, Explainer: English and second-price auctions are called "strategically equivalent". They are outcome-equivalent under private values but not strategically equivalent in general (the Dutch/first-price pair is). Revenue-equivalence conditions omit independence of values. Q3 stem is garbled ("most four standard auction formats").
- auction-theory.md, Q0 explanation: first-price bidders "bid more aggressively than they would in a second-price auction". First-price bids are below value, second-price bids equal value; the statement is wrong as written.
- bertrand-competition.md: no errors found beyond simplification.
- cartel-and-collusion.md, Q3 explanation: "The grim trigger is the harshest sustainable punishment." Not true in general; optimal penal codes (stick-and-carrot) can punish below static Nash payoffs. Q2 explanation: "Each firm's dominant strategy is to produce its best-response quantity" ; Cournot has no dominant strategy.
- collusion-cartel-stability.md, Explainer and Q2: "In a one-shot game, cheating is the dominant strategy" in a Cournot setting; Cournot has no dominant strategy. Core Idea mixes Bertrand language ("undercutting the agreed price") into a Cournot quota setting. Q3 explanation attributes the effect of more firms to the Green-Porter model, which is about demand shocks, not firm count. Q4 explanation claims a threat to exit is "too extreme and therefore not credible", which is not a standard result.
- compensated-demand-curves.md is a near-duplicate of hicksian-demand.md (same concept, same title). Consider merging.
- conditional-factor-demand.md, Core Idea: "Conditional (or derived) factor demand" ; "derived demand" usually means unconditional demand. "unlike Marshallian input demand which conditions on revenue" is wrong: unconditional factor demand depends on output and input prices, not revenue.
- consumer-duality-and-expenditure-function.md, Q4 explanation: Hicksian demand "isolates the efficiency cost (deadweight loss) from the distributional cost" is not accurate as stated. Q2 explanation: the claim that the expenditure function is easier to derive than Hicksian demand is doubtful, since deriving e usually requires solving for h.
- contract-curve.md, Core Idea: "Trade moves the economy along the contract curve." Trade moves the economy to the contract curve.
- cost-function-duality.md, Core Idea: production and cost functions "can be recovered from each other via the envelope theorem". Recovery of technology from the cost function uses convex duality and holds only for convex input requirement sets. Q2 explanation ("All information in the production function is encoded in the cost function") has the same missing convexity condition.
- cost-minimization-duality.md, Core Idea: profit maximization is "cost minimization ... plus revenue maximization". The second step is choosing output to maximize p·y − C(w, y), not revenue maximization.
- cournot-competition.md, Q2 explanation: "(Contrast with Bertrand competition, where strategies are also substitutes, but in price space.)" In differentiated Bertrand, prices are strategic complements.
- edgeworth-box-exchange.md, Q1 explanation: the lens is called "a subset of the contract curve". The lens is a region, and most of it is off the contract curve. Core Idea calls the contract curve "all mutually beneficial allocations", which conflates it with the core.
- extensive-form-games-and-subgame-perfection.md, Explainer: "'enter, and the incumbent fights' can be a Nash equilibrium". (Enter, Fight) is not a Nash equilibrium; the threat-supported equilibrium is (Stay Out, Fight). My misconception bullet states this.
- factor-demands-and-elasticity.md, Core Idea gives the two-input (Hicks) definition but calls it the Allen partial elasticity. Explainer says Allen elasticity holds "other input quantities at their optimal levels", which is unclear. Q3 (false) and Q4: σ near zero does not rule out large employment effects, because of the scale effect. Q4's Leontief incidence claim ("burden stays on capital") is not a general result.
- first-price-auction.md, Explainer: the winner's shaded bid is "higher than the second-highest bid". Not necessarily: with N = 2, v1 = 0.8 and v2 = 0.6, the winner bids 0.4.
- first-welfare-theorem.md, Q2 explanation has an unedited self-correction ("that's a Pareto improvement — wait, no:"). Core Idea and Explainer omit local nonsatiation, which the proof needs.
- general-equilibrium-existence.md, Core Idea lists "no free disposal" as an assumption, which is not a standard existence condition. It also says excess demand maps the simplex to itself; it is the price-adjustment map that does. Q4 answer says non-convex preferences correspond to goods that "exhibit satiation"; satiation is not non-convexity.

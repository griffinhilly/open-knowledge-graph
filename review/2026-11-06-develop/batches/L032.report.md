- bqp-and-quantum-complexity.md, Q0 explanation: "BQP contains problems (like factoring and simulating quantum systems) that are not known to be in NP". The decision version of factoring is in NP (and coNP). Factoring is a poor example of BQP outside NP.
- fault-tolerant-quantum-computation.md, Core Idea: "FTQC requires cascading error-correction codes". Concatenation is one route; surface-code schemes reach fault tolerance by growing code distance without concatenation.
- fault-tolerant-quantum-computation.md, Explainer: "requires poly(d, n) * k qubits". The standard threshold-theorem result is polylogarithmic overhead in circuit size; "poly(d, n)" understates the result's strength and is unclear.
- fault-tolerant-quantum-computation.md, Explainer: "Phase 1 (NISQ): current devices, 0.1%-1% error, no error correction" and "Phase 4 ... billions of qubits". Error-correction experiments already run on current devices; the phase timeline and qubit counts are speculative.
- fault-tolerant-quantum-computation.md, Q1 explanation: "Exceeding the budget at any single gate can cause a logical failure". Budget is an aggregate; a single gate over its share does not by itself cause failure. Minor.

## Flags
- stabilizer-codes.md, Explainer: "The Steane [[7,1,3]] code uses C1 = C2 = the Hamming [7,4,3] code". Wrong. With C1 = C2 the CSS code encodes k1 - k2 = 0 qubits. Steane uses C1 = Hamming [7,4,3] and C2 = its dual, the [7,3,4] simplex code.
- stabilizer-codes.md, Questions item 1 explanation: "E1*E2^dagger is in the stabilizer (or is proportional to a logical operator)". Loose. Same syndrome means E1*E2^dagger lies in the normalizer of S; that splits into the stabilizer case and the nontrivial logical case.

- surface-codes.md, Explainer: the stabilizer-commutation reason ("each edge appears an even number of times in any product of stabilizers from different types") is garbled. The actual reason is that a plaquette and a vertex share either 0 or 2 edges.
- surface-codes.md, Questions item 1 explanation: "probability of d correlated errors scales as p^d". Inconsistent with the (p/p_th)^(d/2) scaling elsewhere in the file. About d/2 errors are enough to fool the decoder.
- surface-codes.md, Explainer: "Clifford gates (H, S, CNOT) can be implemented transversally or via lattice surgery". S is not transversal on the surface code. H is transversal only up to a lattice rotation.
- topological-quantum-computing.md, Questions item 2 explanation: "Abelian anyons ... cannot encode quantum information". Overstated. Abelian anyon models such as the toric code store qubits in topological ground-state degeneracy. They cannot compute by braiding.
- topological-quantum-computing.md, Explainer and Questions item 1: Ising braiding "generates only the Clifford group". Braiding Ising anyons gives a subgroup of the Clifford group, not the full group on many qubits.
- superdense-coding.md, Explainer: "entanglement serves as a catalyst". This conflicts with the same paragraph and the previous one, which say the entanglement is consumed.

Too strong. Shot noise, readout error and error-mitigation extrapolation can give estimates below E_0. The bound holds for the exact expectation value of any state, mixed or pure.
- variational-quantum-eigensolver.md, Explainer: "intractable beyond about 50 electrons". Unsourced figure, and the cutoff depends on the method.

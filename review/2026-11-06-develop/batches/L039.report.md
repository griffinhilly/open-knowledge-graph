- domains/mathematics/differential-geometry/vector-bundles.md, Q2 explanation: "the endomorphism bundle End(E) = E* ⊗ E has fibers GL(Ep)". The fibers of End(E) are End(Ep), all linear maps Ep → Ep. GL(Ep) is only the invertible ones and is not a vector space.
- domains/mathematics/differential-geometry/vector-bundles.md, Q1 (stem and explanation): "admits a nowhere-zero global section if and only if ... The Euler class of E vanishes". This holds for an oriented rank-n bundle over an n-dimensional (closed) manifold. For rank below the base dimension, a vanishing Euler class does not in general guarantee a nowhere-zero section. The stem's "(when defined)" does not state the rank condition.
- domains/mathematics/differential-geometry/vector-bundles.md, Q1 explanation: "e(TM) = χ(M)". Strictly, the Euler class evaluated on the fundamental class equals χ(M), for closed oriented M. Minor.

In Young's formula ρ is the spectral radius of the Jacobi iteration matrix. With the Gauss-Seidel radius it reads 2 / (1 + √(1 − ρ_GS)), since ρ_GS = ρ_J² for consistently ordered matrices.
- successive-over-relaxation.md (Q3 explanation): "SOR is only guaranteed to converge when 0 < ω < 2" and "the iteration diverges regardless of the matrix properties". The range is necessary (Kahan: ρ ≥ |ω − 1|), not a guarantee; the same paragraph then says convergence depends on the matrix. Also "diagonal dominance ... sufficient" holds for 0 < ω ≤ 1, not the whole range; positive definiteness (Ostrowski-Reich) covers 0 < ω < 2.

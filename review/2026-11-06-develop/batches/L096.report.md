Suspected factual errors in existing text:
- chebyshev-nodes.md, Explainer: "T_n(x) = cos(n arccos(x)) is the unique monic polynomial of degree n whose maximum absolute value on [-1, 1] is minimized." T_n is not monic (leading coefficient 2^(n-1)); the minimax monic polynomial is T_n/2^(n-1).
- condition-number.md, Q0: ln(1.0001) gives "wildly inaccurate results". κ ≈ 10⁴ there, so double precision still yields about 12 correct digits. Overstated.
- cubic-spline-interpolation.md, Explainer: "n−1 interior second derivatives give n−1 equations but you have n cubic pieces requiring 4n − 3 constraints." The count is garbled; 4n coefficients, 4n − 2 conditions, 2 boundary conditions (the short-answer question has it right).
- cubic-spline-interpolation.md, Explainer: "O(h⁴) error" stated without qualification. With natural end conditions the error near the ends is generally O(h²) unless f″ vanishes there. Also "Bézier-style curves through control points": Bézier curves do not pass through their interior control points.
- cubic-spline-interpolation.md, Core Idea: "without oscillation" is overstated; splines can overshoot near abrupt data changes.
- euler-method-error-analysis.md, Q0 explanation: "a second-order method (like classical Runge-Kutta)". Classical RK is fourth order.
- euler-method-error-analysis.md, Core Idea: "the total accumulated error grows linearly with integration length". The standard bound grows like (e^{LT} − 1)/L, exponential in T. The Explainer's "does not cause exponential blowup" is likewise only true in h, not in T.
- fixed-point-iteration.md, Explainer and Q2 explanation: "x = x² − x + 2" is not a rearrangement of x² − 2 = 0 (its fixed points solve x² − 2x + 2 = 0). The intended g is likely x − x² + 2, which does give |g′(√2)| ≈ 1.83.
- floating-point-representation-numerical-analysis.md, Explainer: 0.1 "gets truncated". IEEE default is round-to-nearest, not truncation. Minor.
- gauss-seidel-method.md, Q3 explanation: "Symmetric positive definite (SPD) matrices are a special case" of diagonal dominance. False; neither class contains the other.
- gaussian-elimination-with-pivoting.md, Q1 explanation and Explainer: with |m| ≤ 1 "rounding errors are not amplified — they can only stay the same or shrink". False; the growth factor can reach 2^(n−1) under partial pivoting.
- gaussian-quadrature.md, Core Idea: "the most efficient for general-purpose integration". Overclaim (e.g., trapezoidal rule is exponentially convergent for periodic integrands; adaptive methods often preferred).
- interpolation-error-analysis.md, Q2 explanation: "For equally spaced nodes, the maximum of |ω(x)| grows rapidly." On [−1, 1], max|ω| for equally spaced nodes decreases with n, only far more slowly than 2^(−n). Runge divergence is driven by growth of f^(n+1). Q4 answer "regardless of f's behavior" is also overstated.
- runges-phenomenon.md, Q0 and Q4 answer: equally spaced nodes "leave large gaps at the endpoints while packing interior nodes tightly" / "interior nodes are tightly clustered". Equally spaced nodes have equal gaps. Explainer calls Runge "a concrete failure of the second condition" (node product), while the divergence also needs fast derivative growth.
- runges-phenomenon.md, Core Idea: "f(x) = 1/(1+x²)" with no interval; the phenomenon for that form needs [−5, 5] (equivalent to 1/(1+25x²) on [−1, 1]).
- lagrange-polynomial-interpolation.md, Core Idea: "becomes numerically unstable when adding new points since all basis functions must be recomputed". Recomputation cost is not instability; the barycentric Lagrange form is stable and can be updated in O(n). Explainer's O(n²) update cost also ignores the barycentric form.
- lu-decomposition-numerical-numerical-analysis.md, Core Idea: "A = PLU" vs Explainer/Questions "PA = LU". Inconsistent convention (A = PᵀLU if P is the same permutation).
- machine-epsilon.md, Core Idea and Explainer: "smallest positive number such that 1 + ε ≠ 1" is said to equal the gap 2⁻⁵². Under round-to-nearest, the smallest such number is just above 2⁻⁵³, so the two definitions differ. Explainer also writes "ε_mach or u" as if they were the same, then defines u = ε_mach/2. "for 10¹⁵ absolute rounding error can be as large as 0.1": spacing there is 0.125, so max rounding error is about 0.06.
- jacobi-iterative-method.md, Core Idea: "converges slowly unless A is diagonally dominant or well-conditioned". Well-conditioning does not imply Jacobi convergence.

- newton-cotes-formulas.md, Q3 explanation: "beyond degree 4 (Simpson's 3/8 rule)". The 3/8 rule is degree 3 (4 points). Q0 explanation calls option A the "adaptive" misconception; that is option C. - numerical-stability.md, Core Idea: "A numerical algorithm is stable if small perturbations in inputs produce only small changes in outputs." That is the definition of conditioning, not algorithmic stability.
- numerical-stability.md, Q0 and Explainer: p(x) = (x − 2)² near x = 2 is called well-conditioned. Its relative condition number 2|x|/|x − 2| blows up near x = 2; the factored form is accurate because x − 2 is computed exactly, not because the problem is well conditioned.

## Flags
- spring-mass-systems.md, q4 explanation: "Engineers tune the ratio c²/(4mk) — the damping ratio". The damping ratio is ζ = c/(2√(mk)); c²/(4mk) is ζ².
- undetermined-coefficients.md, q1: the keyed answer "A cos(x) + B sin(x)" is not a working guess for y'' + y = sin(x), since sin x and cos x are in y_h. The question's own explanation says the guess must be Ax cos(x) + Bx sin(x). The question needs a non-resonant equation (for example y'' + 4y = sin x) or a different key.
- undetermined-coefficients.md, q2 (true-false, answer true): "the correct guess for y_p is a polynomial of degree n". This fails when 0 is a characteristic root (q = 0); for y'' + y' = x the guess must be x(Ax + B).
- stability-classification.md, Core Idea and Explainer: marginal stability is described as "all eigenvalues are purely imaginary (Re(λ) = 0)". The usual definition is all Re(λ) ≤ 0, with the eigenvalues on the imaginary axis non-defective; eigenvalues −1 and 0 give a marginally stable origin.
- systems-of-first-order-linear-odes.md, Explainer: "The general solution is a linear combination of such solutions, one per eigenvalue." This holds only when A has n linearly independent eigenvectors; a defective repeated eigenvalue needs generalized-eigenvector solutions.
- variation-of-parameters.md, Explainer: the constraint u₁'y₁ + u₂'y₂ = 0 "eliminates the y'' cross-terms". It removes the u₁'' and u₂'' terms. Also q2 explanation: "Without this constraint, the algebra does not reduce to a solvable system" is overstated; the constraint is a convenient choice.
- separation-variables-pde.md, Explainer: "the condition X(0) = 0 forces the solution to be X = sin(nπx/L)". X(0) = 0 gives sin(√λ x); the value √λ = nπ/L comes from X(L) = 0.
- wronskian-linear-independence.md, Core Idea: "the Wronskian is either always zero or never zero" needs the qualifier "for solutions of one linear ODE on an interval where p and q are continuous".
- Prerequisite: fourier-series-definition -> separation-variables-pde. The method fits the initial condition with a Fourier sine series, and the current soft prerequisite systems-of-first-order-linear-odes is a weaker link.

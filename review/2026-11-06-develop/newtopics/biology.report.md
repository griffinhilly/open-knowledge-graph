# New topics report: biology

Status: DONE. 21 new topic files written, all with status: validated. No existing files edited.

Domain size before this pass: 1,065 topics. Coverage of molecular, cell, human-physiology, immunology, microbiology and ecology units is dense, so most of the gaps sit in one area: plant form and function, plus animal diversity. A standard intro textbook teaches these as whole units, and no existing topic covered them.

Course placement note: the domain has no botany course. I put the plant form-and-function topics in `physiology`, since it is the formal-systems course for organism function. I put plant and animal diversity in `ecology-and-evolution`. If a plant-biology course is added later, the seven plant physiology topics should move there.

Stage checks: no new topic is staged below any of its hard prerequisites. monoclonal-antibodies-and-immunoassays is staged `advanced`, so the `expert`-staged antibody-structure-and-function is a soft prerequisite there, not a hard one.

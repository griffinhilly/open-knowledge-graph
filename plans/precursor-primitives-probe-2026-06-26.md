# Precursor-Primitives Convergence Probe — 2026-06-26

**Question (load-bearing):** Do developmental precursor primitives (same/different, binary
contrast, classification, one-to-one correspondence, object permanence, cause/effect,
symbol↔referent, sequencing, part/whole, seriation) CONVERGE to a small origin set — giving
the OKG a true root / "start here" — or SPRAWL into a second flat layer (which would not help)?

**Context:** OKG pre-formal floor is currently 314 disconnected root nodes (314/319 have zero
prerequisites). No shared origin → no clear starting point at the center of the graph. Griffin's
entry observation: "binaries" (hot/cold, happy/sad) absent as a concept; suspects a class of
fundamental child-development concepts is missing. Reframe: precursor primitives could give a
*tighter core* and a parent-facing early-childhood developmental tracker.

## Result: CONVERGENCE CONFIRMED (3 of 4 frameworks converge, to a compatible core)

| Framework | Verdict | Key contribution |
|---|---|---|
| Core-knowledge theory (Spelke/Carey) | **MIXED** | Origin set converges to ~4–6 innate core systems; but Carey bootstrapping says derived concepts are *incommensurable* with inputs — edges are enabling, not reductions |
| Montessori sensorial | **CONVERGES (hard)** | Whole curriculum = 3 operations (Discriminate → Grade → Name) × 8 modalities. Root = "isolate one attribute." Cleanest ordering. |
| Piaget (modern-corrected) | **CONVERGES** | Linear-ish chain: same/different → object permanence → symbolic function → classification → seriation → conservation. Ages wrong, ordering holds. |
| Milestone-tracker landscape | (n/a) | NONE of CDC/ASQ-3/Denver II/Kinedu/Wonder Weeks is prerequisite-graph-based — all flat age-banded. Genuine structural gap. |

## The convergent origin model (synthesized)

**FLOOR — core systems** (innate ~birth; core-knowledge theory, Piaget's corrected floor agrees):
- Objects (cohesion/persistence → object permanence)
- Agents (goal-directed action → first causality)
- Number (approximate magnitude + small-set tracking → one-to-one correspondence)
- Space / geometry
- (Social beings)

**OPERATIONS — the build-up engine** (Montessori spine, cleanest dependency chain):
1. **Discriminate** — isolate one attribute, detect same/different  ← the single root act
2. **Grade / seriate** — order instances along that attribute's gradient
3. **Name** — attach vocabulary; **binary opposites = naming the two gradient endpoints**
   (Montessori three-period lesson, period 1); comparatives/superlatives come *after*
4. **Classify / sort** — group by shared attributes

**GATEWAY — symbolic function** (Piaget's pivotal bottleneck ~18–24mo): once symbol↔referent
mapping is online, language/counting/pretend and the existing 314 pre-formal topics unlock.

→ Dependency spine: core systems → discriminate → grade → name(binaries→comparatives) →
classify → [symbolic function] → 314 pre-formal topics → all knowledge.
Tight neck ≈ ~5 core systems + 4 operations + 1 gateway ≈ ~10 origin nodes. **Hourglass topology
is viable** — the neck is the "start here" Griffin was missing.

## Where "binaries" actually sits (closes the original loop)

Binary opposition is NOT the floor. It's the **naming layer** — the linguistic interface where a
felt gradient (thermic, size, weight) becomes a named, shareable concept. Hot/cold presupposes the
thermic channel + discrimination + grading. That's why it felt fundamental teaching Addi: it's the
moment perception becomes language. Precise placement: step 3 (Name), endpoints-first.

## Caveat (don't overclaim)

Carey: prerequisite edges from core→derived are *enabling conditions*, not "nothing but" reductions
(bootstrapping introduces genuinely novel representational content). Fine for a prerequisite graph —
prereqs are enabling, not reductive — but don't claim derived concepts are mere recombinations.

## Sharpened tension: tight core vs. parent tracker (two artifacts, not one)

- **Tight theoretical core** wants ~10–15 nodes (the hourglass neck). Gives clean starting point.
- **Parent milestone tracker** is inherently WIDE — even leanest validated instrument (CDC 2022)
  is ~70 items across 4 domains; ASQ-3 ~30/age × 21 ages; apps 1,000+. Observation-driven.
- They do NOT collapse into one. Resolution = layered: tiny origin (core+operations) → milestone
  layer hangs off it. Building both = two granularities, two jobs.

## Strategic finding

- **Prerequisite-graph-based developmental tracker = real unfilled gap.** No existing tool does it
  (Kinedu = ML recommendation, not declared prereqs; Wonder Weeks = 10 coarse leaps). Differentiation
  is genuine. Reconnects to the PARKED parent-acquisition wedge — but EARLIER (birth–5, no season)
  and sharper than the school-age version that felt futile.
- **Liability boundary (hard):** stay on enrichment/sequencing side ("here's what typically develops
  next"). NEVER diagnostic inference ("missing X → delay in Y") — that crosses into clinical screening
  (ASQ/Denver/M-CHAT territory, needs validation). CDC moved to 75th-percentile threshold in 2022
  explicitly to cut parental anxiety. COPPA applies if child data entered.

## Open decisions (teed up, not yet made)

1. **Identity:** Is the OKG a curriculum map (floor = preschool curriculum) or a learnability map
   (floor = capacities curriculum presupposes)? Adding the origin layer commits toward the latter.
2. **Ontology:** origin primitives as topics / new node-type / tag? Probe leans **distinct
   sub-pre-formal node-type** (tracked enabling-capacities, not taught-topics).
3. **Scope:** (A) add convergent-core origin layer to graph [low risk, fixes 314-roots defect] /
   (B) build parent tracker on top [higher value+risk] / (C) both, sequenced (A is B's foundation).

## Dialectic verdict (tradeoff, 2-2-1 Opus, 2026-06-26)

The curriculum-vs-learnability binary dissolved into a 5-point spectrum. Referee recommendation:

**RECOMMENDED — (iv) Typed sub-pre-formal origin node-type, in-graph, DECOUPLED from the tracker,
CONSERVATIVE identity framing.** Add the ~10 origin nodes as a distinct type (`tracked-capacity`,
divergent prereq/status semantics, EXCLUDED from keystone/JSON-LD/assessment), wired beneath the
314 roots. Fixes the disconnected-roots defect + anchors path engine/radial — without a public
"everything learnable" rebrand.
**RUNNER-UP — (iii) separate origin annotation artifact** (cheapest, lowest epistemic risk; forgoes
the structural payoff — path engine still dead-ends). Correct fallback if any (iv) assumption breaks.
**NOT RECOMMENDED:** (v) full learnability identity + tracker (imports parked-product risk into a
graph vote); (i) curriculum + UI entry-points (papers over the hole); (ii) soft edges only.

Two factual adjudications (both deflate the original proposal):
- **(a) NO clean center / hourglass.** The origin layer is ~5 PARALLEL core systems (no shared
  super-root) + many-to-many fan-out into 314 roots = a narrowing FUNNEL/MESH, not a single-node
  pinch. Connectedness gain is real; the "true center" marketing is not. **Drop hourglass language.**
- **(b) Blast radius is SMALL, contingent.** "Re-scores all 15,285" only holds if origin nodes are
  wired as untyped hard prereqs (nobody proposes that). Keystone/JSON-LD/assessment already
  exclude/band/special-case by type; per-edge `strength` already passed the Phase-12 gate. Real
  remaining cost: publishing theory-laden dev-psych edges to crawlers + maintaining a 7th sub-type.

**KEY TRADEOFF:** you publish contested developmental-psych claims (which core systems count; where
"binaries" sit) as typed machine-readable edges to crawlers, trading some epistemic modesty to fix
the disconnected-roots defect — and you do NOT get the advertised clean center.

**DECOUPLING (load-bearing):** the graph-layer edit and the parent tracker are SEPARATE votes. The
zero-users base rate / parked-wedge status bind the TRACKER, not the structural fix. The public
"everything learnable" identity rebrand is a THIRD, separate, face-value decision — the structural
edit must not silently force it.

**REVERSAL CONDITIONS:** (1) if 10→314 mapping is so uniformly many-to-many ("discriminate" feeds
everything) that the layer adds no navigational signal → fall back to (iii); (2) if typed exclusion
forces real keystone/JSON-LD rewrites (not config guards) → complexity discount was wrong, reassess;
(3) identity rebrand decided separately at face value; (4) tracker = separately gated, base rate binds.

# Generative Poetry: Algorithmic Composition

## Core Idea
Generative poetry emerges from algorithmic systems—rule-based composition using randomness, constraint, or neural networks. Rather than fixed text, generative systems produce variation; each instantiation is unique. This practice questions authorship and determinism by treating literature as combinatorial exploration rather than singular creation.

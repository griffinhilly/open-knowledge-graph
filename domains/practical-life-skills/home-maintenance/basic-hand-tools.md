# Basic Hand Tools and Their Uses

## Core Idea
Every homeowner needs a small set of hand tools: hammer, flathead and Phillips screwdrivers, adjustable wrench, needle-nose pliers, tape measure, and a level. Each tool has a specific mechanical purpose — a hammer drives nails, a wrench turns fasteners, a level checks flat surfaces. Owning and knowing how to use these tools lets you handle the majority of minor household repairs without calling a professional.

## How It's Best Learned
Handle each tool physically and practice its primary motion — drive a nail, tighten a bolt, measure a board. Keep tools organized in a basic toolbox so they're easy to find when needed.

## Common Misconceptions
- Using the wrong tool for a job (e.g., using a knife as a screwdriver) damages both the tool and the work surface.
- 'A bigger hammer solves every problem' — forcing a fastener strips it and creates a worse problem.

# Discrimination: Same and Different

## Core Idea

The root operation of early cognition: isolating a single attribute — color, size, shape, sound,
texture — and judging whether two things match on it or differ. Almost everything downstream depends
on it. You cannot count without telling like things apart, cannot sort without a basis for grouping,
and cannot compare amounts without registering a difference. It is the hinge between raw perception
and structured thought.

## Emerges Through

Sharpened through matching and contrast: pairing socks, finding the other shoe, matching a lid to a
jar, noticing that two blocks are the same color but different sizes. Montessori sensorial work is
built on exactly this — pairing identical things, then noticing along which single dimension two
things differ.

## Observable Signs

Illustrative, not a checklist:

- Matching identical items — putting like with like.
- Noticing when one thing in a set is the odd one out.
- Reacting to a change in a single feature (a new color, a different sound) while the rest stays put.

Developmental markers vary widely; this is an enrichment map, not a screening tool. For concerns
about a child's development, consult a pediatrician.

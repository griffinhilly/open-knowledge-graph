# Classification and Sorting

## Core Idea

Grouping many things by a shared attribute — putting all the red ones together, separating blocks from
balls. Where discernment compares two things, classification organizes a whole set into categories.
This is the substrate beneath sorting activities, data and graphing, taxonomies, and every later
discipline that carves its subject into kinds.

## Emerges Through

Built through hands-on sorting: putting toys away by type, separating laundry by color, grouping a
mix of buttons. Giving a child mixed collections and a reason to organize them — by where they go, by
what they are — develops the move from noticing a difference to acting on it across a set.

## Observable Signs

Illustrative, not a checklist:

- Putting like things together when given a mixed pile.
- Sorting by one feature (color), then re-sorting the same set by another (shape).
- Explaining a grouping — "these go together because they're round."

Developmental markers vary widely; this is an enrichment map, not a screening tool. For concerns
about a child's development, consult a pediatrician.

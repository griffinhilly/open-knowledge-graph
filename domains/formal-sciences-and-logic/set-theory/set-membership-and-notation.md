# Set Membership and Basic Notation

## Core Idea
A set is a collection determined entirely by membership: an element x either belongs to set S (written x ∈ S) or does not. Two sets are equal if and only if they have exactly the same elements (extensionality). This foundational principle underlies all of set theory.

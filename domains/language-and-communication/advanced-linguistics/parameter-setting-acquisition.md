# Parameter Setting in Language Acquisition

## Core Idea
The parameter-setting model proposes children learn language by setting binary parameters (like the null subject parameter). Rather than learning from scratch, children use input to set switches in the UG system to match their target language. Early errors and vocabulary spurts reflect parameter resetting; acquisition plateaus around age 4-5 when major parameters are set, suggesting a biologically timed acquisition window.

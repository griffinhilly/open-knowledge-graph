# Ring Homomorphisms

## Core Idea
A ring homomorphism φ: R → S preserves both operations: φ(a + b) = φ(a) + φ(b) and φ(ab) = φ(a)φ(b). The kernel is an ideal; the image is a subring. Ring homomorphisms generalize group homomorphisms to two operations.

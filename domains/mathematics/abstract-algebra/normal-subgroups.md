# Normal Subgroups

## Core Idea
A subgroup N is normal if gN = Ng for all g ∈ G, equivalently if gNg^{-1} = N. Kernels of homomorphisms are always normal. Normal subgroups are necessary for quotient group operations to be well-defined.

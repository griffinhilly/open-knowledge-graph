# Quotient Rings

## Core Idea
For an ideal I of R, the quotient ring R/I has cosets as elements with (a + I) + (b + I) = (a + b) + I and (a + I)(b + I) = (ab) + I. R/I is a ring with zero element 0 + I and |R/I| = |R|/|I| when finite.

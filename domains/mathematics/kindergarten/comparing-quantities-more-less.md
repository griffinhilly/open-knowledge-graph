# Comparing Quantities: More, Less, Same

## Core Idea
Children visually compare two sets to determine which has more, which has fewer, or if they have the same number. Comparison is the foundation for understanding number relationships.

## How It's Best Learned
Line up two groups of objects side-by-side. Use 'more' and 'less' repeatedly in daily contexts ("Who has more crackers?"). Use fingers and real objects, not just pictures.

## Common Misconceptions
Comparing by physical size of objects rather than quantity ("This pile is bigger, so it has more"). Not lining objects up for accurate visual comparison.

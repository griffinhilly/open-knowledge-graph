# Comparing Quantities (More, Less, Same)

## Core Idea
Comparing quantities means determining whether one group has more, fewer, or the same number of objects as another. Children can compare by matching (one-to-one) or by counting both groups and comparing the numbers. The vocabulary 'more,' 'fewer,' and 'equal' describes these relationships.

## How It's Best Learned
Use physical matching: line up objects from each group in pairs and see if any are left over. Later compare by counting: 'I counted 5 red and 8 blue; 8 is more than 5.' Use the language consistently in daily contexts.

## Common Misconceptions
- Judging by physical size of objects rather than quantity (e.g., 3 large blocks seems like 'more' than 5 small ones).
- Confusing 'more' and 'less' — these require explicit vocabulary practice.

# Skip Counting by 10s

## Core Idea
Skip counting by 10s means counting 10, 20, 30, 40… by adding one ten each time. The ones digit never changes — only the tens digit increases. This directly models place value and is the conceptual foundation for mentally adding and subtracting tens from any two-digit number.

## How It's Best Learned
Use dimes as a concrete model (each dime = 10 cents). Highlight the tens column on a hundred chart. Show that adding one ten-rod in base-ten blocks changes only the tens digit of the written number.

## Common Misconceptions
- Counting 10, 20, 30, 31, 32… accidentally reverting to counting by 1s after a decade.
- Not connecting skip counting by 10s to the tens digit in two-digit numbers.

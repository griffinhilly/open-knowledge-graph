# Measuring Length with Nonstandard Units

## Core Idea
Measuring length means counting how many copies of a unit fit end-to-end along an object with no gaps or overlaps. Using nonstandard units (paper clips, cubes, hand-spans) shows that measuring gives different numbers when different units are used — motivating the need for standard units. The object being measured must begin at the starting edge of the first unit.

## How It's Best Learned
Measure the same object with multiple nonstandard units and discuss why the numbers differ. Emphasize the 'no gaps, no overlaps' rule with explicit practice. Connect to ordering: a longer object needs more units.

## Common Misconceptions
- Leaving gaps between units, undercounting the length.
- Starting at the end of the object rather than at one edge.
- Not understanding that smaller units yield larger count numbers (inverse relationship).

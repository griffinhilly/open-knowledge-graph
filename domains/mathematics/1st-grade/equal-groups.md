# Equal Groups

## Core Idea
Equal groups are sets containing the same number of objects. Recognizing and counting equal groups develops foundational understanding for multiplication as repeated groups.

## Questions

```yaml
- question: "Which of the following is an example of equal groups?"
  type: multiple-choice
  options:
    - "2 bags with 3 toys and 1 bag with 5 toys"
    - "4 plates each with 2 cookies"
    - "A jar with 6 red and 4 blue marbles"
    - "3 kids each holding a different number of stickers"
  answer: 1
  explanation: "Equal groups means every group contains the same number. Four plates each with 2 cookies is equal because each plate has exactly 2. The other options have groups with different amounts, so they are unequal."

- question: "If you count how many groups there are, that tells you the total number of objects in all the groups."
  type: true-false
  answer: false
  explanation: "Counting the number of groups only tells you how many groups exist, not how many objects are inside them. To find the total, you must count — or add — the objects across all groups. For example, 4 groups of 3 gives 3 + 3 + 3 + 3 = 12, not 4."

- question: "You have 4 bags, and each bag has 2 apples. Explain why this is an example of equal groups, and find the total number of apples."
  type: short-answer
  answer: "It is equal groups because every bag holds the same number (2). The total is 2 + 2 + 2 + 2 = 8 apples."
  explanation: "Equal groups requires that every group contains exactly the same count. When groups are equal, you can find the total by repeatedly adding the group size — one addition for each group."
```

## Explainer

Think about having 3 boxes, and every box has exactly 4 crayons inside. Those are equal groups because each group (each box) holds the same number of objects. "Equal" here just means "the same" — every single group has the same count.

Now think of a different situation: you have 3 pockets, but one has 2 coins, another has 5 coins, and the third has 1 coin. Those are NOT equal groups, because the groups hold different numbers. The count must match in every group.

Why do equal groups matter? When groups are equal, you can find the total without counting every object one by one. If you know there are 5 jars and each jar has 3 marbles, you can add: 3 + 3 + 3 + 3 + 3 = 15. You added the same number five times — that repeated adding is the seed of a powerful idea you will learn later called multiplication.

Equal groups appear everywhere: rows of seats in a classroom (the same number in each row), egg cartons (the same number in each section), packs of crayons (the same number per pack). Learning to spot equal groups — and to describe them by saying "how many groups" and "how many in each group" — is one of the most important building blocks in all of mathematics.

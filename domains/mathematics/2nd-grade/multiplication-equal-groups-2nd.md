# Multiplication as Equal Groups

## Core Idea
Multiplication represents equal groups. 3 groups of 5 is written as 3×5 and equals 15. This is the same as 5+5+5. Understanding groups helps students see multiplication as a shortcut for repeated addition.

## How It's Best Learned
Use objects like counters or drawings to make equal groups. Show how 3×5 and 5×3 create different arrangements but have the same total. Use real-world contexts like 4 bags with 3 apples each.

## Common Misconceptions
- Confusing which number represents the number of groups (3×5 means 3 groups, not 5 groups)
- Thinking 3×5 and 5×3 give different answers
- Not connecting to repeated addition

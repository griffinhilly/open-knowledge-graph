# Multiplication: Equal Groups Model

## Core Idea
Multiplication describes repeated equal groups. If you have 3 groups of 4 objects each, multiplication (3 × 4) tells you there are 12 objects total. The first number is the number of groups; the second is the size of each group.

## How It's Best Learned
Use counters, drawings, or objects to create visible groups. Have students count the total and record it as a multiplication sentence. Progress from concrete to pictorial to abstract.

## Common Misconceptions
- Confusing which number represents groups and which represents the group size.
- Counting some objects more than once.
- Not recognizing that 3 × 4 and 4 × 3 result in the same total (commutative property).

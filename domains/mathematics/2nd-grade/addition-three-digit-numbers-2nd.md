# Three-Digit Addition

## Core Idea
Adding three-digit numbers uses the same strategy as two-digit addition: add ones first, then tens, then hundreds, regrouping when needed. Most problems involve one regrouping step.

## How It's Best Learned
Start with addition that requires regrouping in ones but not tens (245+128). Progress to problems needing regrouping in tens (237+156). Use vertical format and check by adding in a different order.

## Common Misconceptions
- Forgetting to add regrouped amounts in higher places
- Adding columns in the wrong order
- Adding hundreds to tens when regrouping

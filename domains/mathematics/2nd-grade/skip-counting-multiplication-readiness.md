# Skip Counting as Preparation for Multiplication

## Core Idea
Skip counting by 2s, 5s, and 10s is an efficient way to add equal groups. When you count 2, 4, 6, 8, 10, you are counting four groups of 2. This bridges counting to multiplication thinking.

## How It's Best Learned
Start with physical groups (2 pennies, 2 more, 2 more) while skip counting. Use number lines and hundred charts to see skip-counting patterns visually.

## Common Misconceptions
- Confusing skip counting with the groups it represents.
- Not recognizing the connection to repeated addition.
- Losing count of how many groups have been counted.

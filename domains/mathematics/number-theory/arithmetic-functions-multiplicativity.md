# Arithmetic Functions and Multiplicativity

## Core Idea
An arithmetic function is a function f: ℕ → ℂ. A function is multiplicative if f(mn) = f(m)f(n) when gcd(m,n) = 1, and completely multiplicative if this holds for all m,n. Multiplicative functions are determined by their values on prime powers.

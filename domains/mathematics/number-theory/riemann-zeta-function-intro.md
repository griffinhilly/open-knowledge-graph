# Introduction to the Riemann Zeta Function

## Core Idea
The Riemann zeta function ζ(s) = Σ 1/n^s has an Euler product ∏_p 1/(1 − 1/p^s), intimately connecting it to primes. Its analytic properties, particularly the location of zeros, govern prime distribution. The Riemann Hypothesis—that all non-trivial zeros lie on the critical line Re(s) = 1/2—remains unproven.

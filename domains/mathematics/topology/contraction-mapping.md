# Contraction Mapping Theorem (Banach Fixed Point)

## Core Idea
If f: X → X is a contraction (∃c < 1 with d(f(x), f(y)) ≤ c·d(x,y)) on a complete metric space, then f has a unique fixed point and iterates converge to it.

# Metric Spaces: Definition and Examples

## Core Idea
A metric space is a set with a distance function d satisfying non-negativity, symmetry, and the triangle inequality. Metrics provide concrete examples of topological spaces; every metric induces a natural topology via open balls. Metric spaces unify analysis, geometry, and topology under a common framework.

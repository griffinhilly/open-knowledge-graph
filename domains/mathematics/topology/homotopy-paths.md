# Homotopy of Paths

## Core Idea
Two paths γ, σ: [0,1] → X with the same endpoints are homotopic if there is a continuous deformation H: [0,1] × [0,1] → X connecting them while keeping endpoints fixed. Homotopy is an equivalence relation on paths.

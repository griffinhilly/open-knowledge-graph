# Urysohn's Lemma

## Core Idea
In a normal space, for any disjoint closed sets F₁, F₂, there exists a continuous f : X → [0,1] with f(F₁) = {0} and f(F₂) = {1}. This shows normal spaces have 'enough' continuous real-valued functions to separate closed sets.

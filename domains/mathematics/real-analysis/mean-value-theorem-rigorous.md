# Mean Value Theorem (Rigorous)

## Core Idea
If f is continuous on [a, b] and differentiable on (a, b), then there exists c in (a, b) such that f'(c) = (f(b) − f(a)) / (b − a). The rigorous proof uses Rolle's Theorem (a special case where f(a) = f(b)) and the extreme value theorem. The MVT is fundamental to relating derivatives to global properties of functions.

# Random Variables as Measurable Functions

## Core Idea
A random variable X is a measurable function from a probability space (Ω, ℱ, P) to ℝ, meaning preimages of Borel sets are in ℱ. This ensures events like {X ≤ x} are well-defined and have probabilities. The measurability condition connects abstract sample spaces to observable numeric outcomes, unifying discrete and continuous cases.

# Hölder's Inequality

## Core Idea
For 1 < p < ∞ with 1/p + 1/q = 1, Hölder's inequality states ∫|fg| ≤ ‖f‖_p ‖g‖_q. This is the key inequality enabling duality in L^p theory. When p = q = 2, it reduces to Cauchy–Schwarz.

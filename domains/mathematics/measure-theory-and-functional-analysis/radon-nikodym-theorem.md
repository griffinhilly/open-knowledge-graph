# Radon-Nikodym Theorem

## Core Idea
If ν is σ-finite and absolutely continuous with respect to μ, then ∃h measurable: ν(A) = ∫_A h dμ. The Radon-Nikodym derivative dν/dμ = h formalizes differentiation of measures.

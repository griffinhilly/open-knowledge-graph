# Measurable Functions: Definition and Properties

## Core Idea
A function f: X → ℝ is measurable if the preimage of every Borel set in ℝ is a measurable set in X (i.e., f⁻¹(B) ∈ ℱ for all B ∈ ℬ(ℝ)). Measurable functions are precisely those we can integrate.

## How It's Best Learned
Start by showing continuous functions are measurable (preimages of open sets are open). Build to indicator functions of measurable sets.

## Common Misconceptions
Measurability differs from continuity; discontinuous functions can be measurable. You only need f⁻¹(open interval) measurable, not f⁻¹(single point).

## Explainer

You already know that a **σ-algebra** ℱ on a set X is a collection of "measurable" subsets — a structured family closed under complements and countable unions. Measurability of a function is defined by asking: does the function respect this structure? Specifically, f: X → ℝ is **measurable** if the preimage f⁻¹(B) = {x ∈ X : f(x) ∈ B} is in ℱ for every Borel set B in ℝ. The Borel sets are the σ-algebra generated by open intervals on ℝ, so this condition says: whenever you take a "natural" subset of the output space, the set of inputs that land there is a measurable set.

Why preimages? The key insight is that preimages preserve all set operations: f⁻¹(Bᶜ) = (f⁻¹(B))ᶜ and f⁻¹(∪Bᵢ) = ∪f⁻¹(Bᵢ). This means if you know f⁻¹ sends the generators of the Borel σ-algebra (open intervals) to measurable sets, then f⁻¹ sends all Borel sets to measurable sets — you get the full condition for free. This is why checking measurability is simpler than it looks: you only need to verify that f⁻¹(a, b) ∈ ℱ for all open intervals (a, b), or equivalently f⁻¹(−∞, c) ∈ ℱ for all c ∈ ℝ.

Continuous functions are automatically measurable. If X = ℝ with the Borel σ-algebra and f is continuous, then the preimage of every open set is open, and open sets are Borel sets. But measurability is strictly weaker than continuity — the **indicator function** of a measurable set E, defined as 1_E(x) = 1 if x ∈ E and 0 otherwise, is measurable even when E is a highly discontinuous set like the Cantor set or a measurable but non-open set. This is exactly why measure theory extends integration beyond Riemann's reach: we can integrate 1_E, and its integral is just the measure of E.

Measurable functions are the class precisely suited for the Lebesgue integral. The path forward is to integrate **simple functions** (finite linear combinations of indicator functions of measurable sets) first, then approximate general measurable functions by simple functions from below. This approximation works because measurable functions are closed under limits: a pointwise limit of measurable functions is measurable, provided the limit exists. Continuity has no such property — a limit of continuous functions need not be continuous. Measurability is the correct, more permissive condition that makes the Lebesgue theory coherent.

# Uniform Boundedness Principle

## Core Idea
If {Tₐ} is a family of bounded operators on a Banach space X with sup_a ‖Tₐ(x)‖ < ∞ for all x, then sup_a ‖Tₐ‖ < ∞. Pointwise boundedness implies uniform boundedness.

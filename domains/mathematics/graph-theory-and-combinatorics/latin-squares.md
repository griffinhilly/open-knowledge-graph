# Latin Squares and Orthogonal Latin Squares

## Core Idea
A Latin square of order n is an n×n array filled with n symbols such that each symbol appears once in each row and column. Orthogonal Latin squares have the additional property that each ordered pair of symbols appears exactly once when superimposed. These structures are fundamental in combinatorial design theory.

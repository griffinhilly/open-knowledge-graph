# Integer Partitions and Partition Functions

## Core Idea
An integer partition of n is a way of writing n as a sum of positive integers, ignoring order. The partition function p(n) counts partitions of n. Generating functions (especially Euler's product formula) and bijections (Ferrers diagrams) are key tools for understanding partition properties.

# Multiplication with Arrays

## Core Idea
Arrays organize objects into rows and columns. A 3-by-4 array represents 3 × 4 = 12. Arrays make the commutative property visible and connect multiplication to area.

## How It's Best Learned
Create arrays with counters or draw on grid paper. Compare different arrangements.

## Common Misconceptions
Mixing up rows and columns; misounting when arrays are larger.

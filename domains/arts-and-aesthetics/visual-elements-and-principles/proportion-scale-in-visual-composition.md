# Proportion and Scale in Visual Composition

## Core Idea
Proportion refers to the mathematical relationships between the sizes of objects and elements in a composition; scale refers to how size appears relative to a reference point or surrounding context. Manipulating proportion and scale affects visual weight, emphasis, and narrative meaning in powerful ways.

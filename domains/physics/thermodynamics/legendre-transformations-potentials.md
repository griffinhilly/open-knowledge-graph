# Legendre Transformations and Thermodynamic Potentials

## Core Idea
Legendre transformations swap independent variables in thermodynamic functions while preserving information. Starting from U(S,V), we obtain F(T,V) = U - TS, H(S,P) = U + PV, and G(T,P) = U - TS + PV. Each potential is natural for different experimental conditions; all contain identical physics.

# State Variables and Thermodynamic Functions

## Core Idea
State variables are properties that uniquely specify a thermodynamic system's condition (pressure, volume, temperature, internal energy, entropy). State functions depend only on initial and final states, not on the path taken between them. Changes in state functions are independent of process details; ∮ dU = 0 around any closed cycle.

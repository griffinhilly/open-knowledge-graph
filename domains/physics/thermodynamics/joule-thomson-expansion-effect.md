# The Joule-Thomson Effect and Temperature Change in Throttling

## Core Idea
In Joule-Thomson expansion (throttling through a restriction), enthalpy H is constant, but temperature changes for real gases. The Joule-Thomson coefficient μ_JT = (∂T/∂P)_H is positive (gas cools) when attractions dominate, negative (gas heats) when repulsions dominate. An inversion temperature exists below which μ_JT > 0 for most gases.

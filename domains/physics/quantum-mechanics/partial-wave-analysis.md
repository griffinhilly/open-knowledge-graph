# Partial Wave Analysis

## Core Idea
Expand the scattering amplitude in partial waves f(θ) = Σ_{l=0}^∞ (2l+1)/(2k) f_l P_l(cosθ) where each partial wave l contributes independently. For spherically symmetric potentials, the phase shift δ_l encodes the phase and amplitude changes in each partial wave. Low energy scattering is dominated by s-wave (l=0); higher l-waves contribute increasingly at higher energies. This reveals resonances in scattering.

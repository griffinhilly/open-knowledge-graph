# Relative Motion and Reference Frames

## Core Idea
The position, velocity, and acceleration of an object depend on the choice of reference frame. Understanding how to transform quantities between frames using Galilean transformations is essential for analyzing motion. Velocity is relative—there is no absolute reference frame in classical mechanics, only the relationship between different frames.

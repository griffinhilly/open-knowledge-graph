# Instruction Decoding and Control Signal Generation

## Core Idea
Instruction decoding converts a binary instruction into control signals that direct the datapath. The decoder examines the opcode and operand specifiers to determine: which ALU operation, which register to read/write, memory access type, and branch target. Control signals are either hardwired from the instruction bits or generated by a microprogrammed ROM.
